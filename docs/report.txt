4. RELATIONSHIPS BETWEEN CLASSES
================================================================================

CUSTOMER AND ACCOUNT
--------------------

Account HAS-A Customer.

Example:

Customer c1 = new Customer(...);

Account a1 = new Account(c1, ...);


Relationship:

        ┌───────────────┐
        │   Customer    │
        │   object      │
        └───────▲───────┘
                │
                │ reference
                │
        ┌───────┴───────┐
        │    Account    │
        │    object     │
        └───────────────┘


Meaning:

An Account contains a reference to a Customer object.

It does NOT mean:

Account IS-A Customer.

Therefore Account does NOT extend Customer.

5. INHERITANCE RELATIONSHIP
================================================================================

SavingsAccount IS-A Account.

CurrentAccount IS-A Account.

Therefore:

                         Account
                            ▲
                            │
               ┌────────────┴────────────┐
               │                         │
               │ extends                 │ extends
               │                         │
               │                         │
        SavingsAccount             CurrentAccount


This allows both child classes to reuse common Account functionality.

8. ACCOUNT CLASS
================================================================================

Account represents a general bank account.

Fields:

    private String accountNumber;
    private double balance;

    Account(Customer accountHolder,
            String accountNumber,
            double balance)


Methods:

    getAccountNumber()
    getBalance()
    deposit()
    withdraw()
    checkBalance()
    displayAccountDetails()


Additional protected method:

    protected void reduceBalance(double amount)


Purpose of reduceBalance():

Allows subclasses to modify the balance through controlled behavior
without directly accessing the private balance field.


================================================================================
9. SAVINGS ACCOUNT
================================================================================

SavingsAccount extends Account.

Additional field:

    private double interestRate;


Constructor:

    SavingsAccount(
        Customer accountHolder,
        String accountNumber,
        double balance,
        double interestRate
    )


Additional method:

    calculateInterest()


Formula:

    Interest = Balance × Interest Rate / 100


Example:

    Balance = 10,000
    Interest Rate = 5%

    Interest = 10,000 × 5 / 100
            = 500


Savings Account withdrawal rule:

    Minimum balance = 1,000

Example:

    Balance = 10,000
    Withdrawal = 8,000
    Remaining = 2,000

    Allowed


    Balance = 10,000
    Withdrawal = 9,500
    Remaining = 500

    Not Allowed


SavingsAccount overrides:

    withdraw()

    displayAccountDetails()


================================================================================
10. CURRENT ACCOUNT
================================================================================

CurrentAccount extends Account.

Additional field:

    private double overdraftLimit;


Constructor:

    CurrentAccount(
        Customer accountHolder,
        String accountNumber,
        double balance,
        double overdraftLimit
    )


Current account supports overdraft.

Example:

    Balance = 5,000
    Overdraft Limit = 20,000

    Maximum withdrawal:
    5,000 + 20,000 = 25,000


Therefore:

    withdraw(15,000)
    → Allowed


    withdraw(25,000)
    → Allowed


    withdraw(25,001)
    → Rejected


CurrentAccount overrides:

    withdraw()

    displayAccountDetails()

12. super() CONCEPT
================================================================================

Child classes use:

    super(accountHolder, accountNumber, balance);


Purpose:

    Calls the constructor of the parent class.

Parent:

    Account

Child:

    SavingsAccount
    CurrentAccount


Flow:

    SavingsAccount constructor
             │
             ▼
        super(...)
             │
             ▼
       Account constructor
             │
             ▼
      common fields initialized


The child only initializes its own additional fields.


================================================================================
13. METHOD OVERRIDING
================================================================================

Parent class:

    Account

    public void withdraw(double amount)


SavingsAccount:

    @Override
    public void withdraw(double amount)


CurrentAccount:

    @Override
    public void withdraw(double amount)


This means:

    Same method name
    Same parameters
    Different implementation in child class


Concept:

    METHOD OVERRIDING


Purpose:

Allows child classes to provide specialized behavior.


================================================================================
14. ACCESS MODIFIERS
================================================================================

private
-------

Used for internal object state.

Example:

    private double balance;


Only Account can directly access balance.


public
------

Used when functionality should be available to other classes.

Examples:

    public void deposit()
    public void withdraw()
    public double getBalance()


protected
---------

Used for controlled access by subclasses.

Example:

    protected void reduceBalance(double amount)


CurrentAccount can call:

    reduceBalance(amount);


But it cannot directly access:

    balance


because balance is private.


================================================================================
15. ENCAPSULATION
================================================================================

Account contains:

    private double balance;


Other classes cannot directly do:

    account.balance = 50000;


Instead, controlled methods are provided:

    deposit()
    withdraw()
    getBalance()


The object controls how its internal state changes.


Concept:

    ENCAPSULATION


Basic idea:

    Hide internal state
           +
    expose controlled behavior

16. POLYMORPHISM
================================================================================

Java allows:

    Account account1 = new SavingsAccount(...);

    Account account2 = new CurrentAccount(...);


Reference type:

    Account


Actual objects:

    SavingsAccount
    CurrentAccount


Diagram:

        Account reference
              │
       ┌──────┴──────┐
       │             │
       ▼             ▼
 SavingsAccount  CurrentAccount
    object          object


When a method is overridden, Java uses the actual object's implementation
at runtime.

25. KEY OOP LESSONS LEARNED
================================================================================

1. A class is a blueprint for objects.

2. An object is an instance of a class.

3. A reference variable points to an object.

4. private fields protect internal state.

5. public methods provide controlled access to behavior.

6. A getter provides controlled read access.

7. Composition represents HAS-A relationships.

8. Inheritance represents IS-A relationships.

9. extends creates an inheritance relationship.

10. super() calls the parent constructor.

11. @Override allows a child to provide specialized behavior.

12. private members are not directly accessible from child classes.

13. protected members can provide controlled subclass access.

14. A parent reference can refer to a child object.

15. ArrayList<Account> can store SavingsAccount and CurrentAccount objects.

16. Polymorphism allows common code to work with different child objects.
